# 并发阶段栅栏

批处理的多个分片有时必须全部准备就绪，才能进入提交阶段。`Barrier` 是一次性栅栏：第 `target` 个调用者到达时同时释放所有等待者；未到齐时仍可用 `context` 退出等待。

```go
barrier := concurrencyphasebarrier.New(3)
go func() { _ = barrier.Arrive(ctx) }()
// 其余两个分片同样调用 Arrive；第三个到达时所有等待者继续执行。
```

调用方取消只停止自身等待，已经登记的到达仍然计入本轮，避免撤销时与释放竞争。它适合固定成员的一次性阶段协调；可复用的多轮同步应使用专门的状态机。
