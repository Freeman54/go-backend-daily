# 有限负载一致性哈希

普通一致性哈希能减少节点变动时的键迁移，却无法阻止热点键压垮其主节点。`Ring` 先找到顺时针主节点；若该节点超过“平均负载 × 系数”，则继续沿环寻找仍在负载界限内的节点。

```go
ring, _ := consistent_hash_bounded_load.New([]string{"cache-a", "cache-b", "cache-c"}, 128, 1.25)
node, err := ring.Pick("tenant:42", currentLoads)
```

虚拟节点改善分布，负载上界提供热点逃生通道。生产环境应使用短周期、同口径的负载快照，并在路由结果变化时权衡缓存命中率；若所有节点都超限，应明确拒绝或进入降级路径。
