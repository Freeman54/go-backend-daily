# 用迟滞水位稳定队列背压

只设一个队列深度阈值时，深度在临界值附近波动会让“接收/拒绝”状态频繁切换。`Controller` 使用高低两个水位：达到高水位开始削峰，只有回落到低水位才恢复。

```go
controller, _ := queue_backpressure_hysteresis.New(100, 500)
if controller.Observe(queueDepth) {
    // 返回 429、降低生产速率或转入降级路径
}
```

控制器带互斥保护，可由多个采样协程调用。水位需要结合消费速率、允许排队延迟和突发流量校准；队列深度只是信号，仍应配合请求超时与容量指标。
