# 滚动错误预算

固定时间点清零的计数器会在窗口边界产生突变。`Budget` 保存最近 N 秒的请求结果，并用滚动窗口内的
错误比例决定是否继续放行，可作为依赖保护或降级策略的简单信号。

```go
budget, _ := New(30, 0.05)
budget.Record(time.Now(), callErr == nil)
if !budget.Allow(time.Now()) {
	return cachedResponse, nil // 暂停调用不健康的依赖
}
```

没有样本时默认放行，等于阈值时也放行。示例为突出算法而保存每条观测；高流量服务应改用秒级环形
桶，并设置最小样本数、恢复探测和指标告警，避免少量失败触发剧烈抖动。
